# Review checklist (run on screenshots)

- [ ] Exactly one hue visible (plus neutrals). Count colours: anything not a step of the hue is a bug.
- [ ] Hero is obvious within 1 s; nothing else competes.
- [ ] No text clipped, overlapping, or wrapping a unit onto its own line; Hindi/Gujarati at 2x font still fits.
- [ ] All text pairs ≥ 4.5:1 (≥ 3:1 for ≥ 18 sp bold).
- [ ] Out-of-range values look different in material, not only colour; check in greyscale.
- [ ] Tabs, pages, chips animate; ambient background moves slowly; reduce-motion disables loops.
- [ ] Card radii, paddings, icon sizes identical across screens.
- [ ] Light and dark both reviewed; glass legible on the brightest blob position.
- [ ] Touch targets ≥ 48 dp; TalkBack labels on every icon button and gauge.
